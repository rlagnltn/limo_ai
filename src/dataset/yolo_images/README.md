# LIMO 촬영 영상의 YOLO 데이터

모델 학습과 ROS2 프로그램 수정 없이 실제 영상에서 만든 데이터입니다.

사진 167장: 학습용 91장, 검증용 76장. 원본 영상 6개, 서로 다른 원본 프레임 67개를 사용했습니다.

- images/train, images/val: 박스나 글씨가 없는 크롭 사진.
- labels/train, labels/val: 같은 기본 이름의 YOLO 라벨 TXT.
- annotated/train, annotated/val: 박스와 클래스 이름을 표시한 확인용 사진. 학습 입력으로 사용하지 않습니다.
- manifest.csv, manifest.jsonl: 사진별 원본 영상, 프레임 번호, 시간, 크롭 좌표 및 라벨 좌표.
- data.yaml, classes.txt: 기존 YOLO 클래스 순서와 일치하는 설정.

사진 한 장과 그 라벨 및 확인용 사진을 저장한 다음 다음 사진을 처리했습니다. 여러 사진을 합친 이미지는 학습 데이터에 넣지 않았습니다.

라벨 형식은 class_id x_center y_center width height입니다. 좌표는 각 크롭 사진의 가로·세로에 대해 0~1로 정규화했습니다. 종횡비를 왜곡하거나 사진을 확대하지 않았습니다. 이 파이프라인은 임의의 정사각형 변환을 요구하지 않습니다.

실제로 라벨링한 대상은 1=slow_down(서행 표지판), 6=pedestrian(보행자 표지판), 7=traffic_cone(라바콘)입니다. 0~6은 기존 best.pt의 클래스 순서를 유지하고 7에 라바콘을 추가했습니다. 나머지 클래스의 새 학습 사진은 없습니다. 표지판은 지지대가 아닌 표지판 판면에 박스를 지정했습니다.

표지판 영상은 1초 간격 후보에서 흐림·가림을 선별하고 모델의 제안 박스를 화면으로 검수했습니다. 서행 표지판을 speed_up으로 예측한 경우 실제 표지 내용에 따라 slow_down으로 수정했습니다. 라바콘은 5초 간격 후보 중 19개 장면을 확인하고 개별 박스를 지정했습니다. 원거리의 겹친 물체를 불확실하게 라벨링하는 대신 필요한 전경 영역으로 크롭했습니다. 라바콘 장면 크롭과 개별 객체 주변 크롭을 함께 저장했으며, 개별 크롭에 같이 보이는 이웃 객체도 좌표를 잘라 라벨에 포함했습니다.

같은 원본 프레임에서 나온 사진은 모두 같은 분할에 있습니다. 라바콘은 _01/_02 영상을 학습용, _01_1/_02_1 영상을 검증용으로 구분했습니다. 표지판은 앞쪽 시간대와 뒤쪽 시간대로 나누고 그 사이 후보를 제외했습니다. 검증 자료도 같은 실내 촬영 환경에서 얻은 자료이며 독립적인 외부 환경 시험 세트는 아닙니다.

개별 박스는 annotated 폴더와 원본 영상을 대조해 확인할 수 있고, 좌표와 분할 근거는 manifest.jsonl에 기록했습니다.
